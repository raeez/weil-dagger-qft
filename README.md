# Weil--Dagger Positivity and Quantum Field Theory

This repository studies the recognition problem for an independently positive
state whose two-point form matches the Weil explicit-formula form. The seed
paper proves an abstract transfer lemma only. It does not construct such a
state, a Hilbert--Pólya operator, or a quantum field theory, and it never inserts
zeta zeros into a spectrum by definition.

Build with `make check`.
